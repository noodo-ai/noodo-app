# Vision Draft

## Positioning

Noodo is an intelligent operating agent for data platforms. Through extensible, purpose-built workspaces, it helps teams manage the complete data lifecycle—from ingestion and transformation to delivery and consumption.

## Product Vision

Noodo's long-term vision is to become the intelligent operating layer above the data platform. It understands an organization's data assets, technical environment, and business goals, then plans and coordinates work across the full lifecycle: ingestion, development, transformation, governance, delivery, analytics, and consumption. Users describe the outcome they want, and Noodo orchestrates the right capabilities while keeping the process, status, and results visible. The goal is to make complex data platforms understandable, operable, and able to evolve.

Noodo is not a standalone data tool, nor is it intended to replace any single existing system. Instead, specialized workspaces support different stages of the data lifecycle while sharing context, access controls, and execution state. Together, they turn fragmented data systems into a continuous, coordinated, agent-driven path from raw data to business value.

## Farm: A Data Engineering IDE

Farm is Noodo's first specialized workspace: an agent-native IDE for data platforms. It brings code editing, version control, deployment, and execution into one workflow, reducing tool switching and context loss.

Planned core capabilities include:

- Creating, editing, and organizing SQL files.
- Committing changes to Git and managing branches, merges, and conflicts.
- Defining CI/CD pipelines in YAML.
- Deploying and running data jobs, with access to status, logs, and results.
- Using an agent to generate, review, modify, and troubleshoot data engineering workflows.

Farm is only the starting point for Noodo's broader capability system. Future workspaces will extend across ingestion, processing, governance, delivery, and consumption, connected through one consistent agent experience.
